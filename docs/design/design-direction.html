Type

  • Inter for all UI text; tabular numerals for metrics
  • JetBrains Mono only for IDs (reg no, VIN, device ID) and parameter values
  • Dot-matrix display font retired

What changes vs. the current app

  • Red accent → single teal accent; red reserved for problems
  • Long stacked card → tabbed card (Overview / Parameters / Device)
  • Absolute timestamps → relative freshness (“2 min ago”), absolute on hover
  • Dial gauges → compact metric tiles + battery ring
  • Solid panels → translucent glass over the map
